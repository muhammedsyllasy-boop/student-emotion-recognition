# Student Emotion Recognition Using Deep Learning

A student-project prototype using a Convolutional Neural Network (CNN) to classify facial-expression images into seven FER-2013 labels: Angry, Disgust, Fear, Happy, Sad, Surprise, and Neutral.

## Important limitations
Facial-expression labels do not establish a person's internal emotion. This project is for learning and research only. Do not use its output to grade, diagnose, discipline, monitor, or make consequential decisions about students. Obtain permission before processing anyone's image.

## 1. Requirements
- Python 3.10 or 3.11 recommended
- Internet connection to install packages and download the dataset
- Several GB of free disk space for dataset, packages, and model
- CPU training works but may take a long time; a compatible GPU can speed it up.

## 2. Download the dataset
Download FER-2013 from a dataset page such as:
https://www.kaggle.com/datasets/msambare/fer2013

Kaggle may require an account and acceptance of its terms. The CSV is not included in this ZIP because it is large and is distributed under the dataset provider's terms.

Your uploaded dataset is an **image-folder ZIP**, not the original CSV. I placed it at `data/fer2013_images.zip`. The updated `train.py` automatically extracts and reads this ZIP. You can also use the original CSV by placing it at `data/fer2013.csv`; the CSV will be preferred if both are present.

The CSV should have columns named `emotion`, `pixels`, and `Usage` (capitalisation is handled). The usual Usage values are `Training`, `PublicTest`, and `PrivateTest`.

## 3. Create an environment (Windows PowerShell)
Open a terminal in this folder:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, use Command Prompt instead:
```bat
.venv\Scripts\activate.bat
```

If you use Anaconda, you can instead create and activate a conda environment:
```bash
conda create -n emotion_env python=3.11 -y
conda activate emotion_env
pip install -r requirements.txt
```

## 4. Train the CNN
Make sure `data/fer2013_images.zip` is in the `data` folder (already included in this project ZIP), then run:

```bash
python train.py
```

The training script:
- reads the original FER-2013 CSV;
- normalises 48x48 grayscale pixels to 0–1;
- uses the provided Training partition and a stratified validation split;
- uses PrivateTest for final evaluation when available (otherwise PublicTest);
- trains a CNN with early stopping and model checkpointing;
- writes a trained model to `models/best_model.keras`;
- writes metrics, a classification report, accuracy/loss curves, and confusion matrix to `outputs/`.

Training can take a while on a CPU. For an initial smoke test, you may edit `epochs=25` in `train.py` to `epochs=2`; do not report this quick run as final model performance.

## 5. Start the web app
After training completes:

```bash
streamlit run app.py
```

Open the local URL printed in the terminal, usually `http://localhost:8501`.

Upload a JPG or PNG and click **Predict facial expression**. The app expects a reasonably clear, single-face image. This simple version resizes the whole image and does not perform automatic face detection.

## 6. Common problems
- **Dataset not found:** check the exact path `data/fer2013.csv`; Windows sometimes saves it as `fer2013 (1).csv`.
- **Wrong CSV format:** check that `emotion`, `pixels`, and `Usage` columns exist and that each pixels entry contains 2304 numbers.
- **TensorFlow install errors:** use Python 3.10/3.11 in a fresh environment and install requirements there. Do not install packages into a different environment from the one used to run the app.
- **App says model not found:** run `python train.py` successfully first.
- **Training is slow:** reduce epochs for a smoke test, close other heavy applications, or use a machine with a supported GPU.
- **Port is busy:** run `streamlit run app.py --server.port 8502`.

## 7. FER-2013 label mapping
This implementation uses the standard integer mapping in the original CSV:
0 Angry, 1 Disgust, 2 Fear, 3 Happy, 4 Sad, 5 Surprise, 6 Neutral.

## 8. Outputs to include in the project report
Use actual results generated by your run:
- test accuracy and test loss from `outputs/metrics.json`;
- class precision, recall, and F1 from `outputs/classification_report.json`;
- `outputs/confusion_matrix.png`;
- `outputs/accuracy_curve.png`;
- `outputs/loss_curve.png`.

Do not invent accuracy values. A benchmark score does not prove that the model reads real classroom emotions accurately.
